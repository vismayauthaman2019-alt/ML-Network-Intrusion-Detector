# ML Network Intrusion Detector

## Project Description
This project implements a Machine Learning Network Intrusion Detector using Python and Scikit-learn. It analyzes network traffic logs and classifies connections as either 'normal' or 'anomalous' to identify potential cyber threats. 

## Technologies Used
* Python 3
* Scikit-learn, Pandas, Numpy

## Dataset
Uses the publicly available [KDDCup99 Dataset](http://kdd.ics.uci.edu/databases/kddcup99/kddcup99.html), fetched via the `sklearn.datasets` API.

## Setup and Run Instructions
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Execute the Jupyter Notebook to train and evaluate the Random Forest Classifier.
